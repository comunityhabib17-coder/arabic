# Balaghah Academy

Website pembelajaran mandiri yang berfokus pada Ilmu Balaghah, dengan antarmuka berbahasa Indonesia dan contoh-contoh bahasa Arab.

## Fitur
- Tiga cabang Ilmu Balaghah: Ma'ani, Bayan, dan Badi'.
- 12 topik pembelajaran dengan definisi, penjelasan, contoh Arab, terjemahan, dan analisis.
- Pencarian dan filter materi.
- Kuis interaktif 10 soal dengan penilaian dan pembahasan.
- Glosarium istilah Balaghah.
- Progres materi tersimpan di browser menggunakan localStorage.
- Desain responsif untuk desktop dan ponsel.

## Menjalankan di komputer
Cukup buka `index.html` di browser. Tidak membutuhkan instalasi atau database.

## Deploy ke Vercel
1. Ekstrak ZIP ini.
2. Unggah folder proyek ke repository GitHub.
3. Masuk ke Vercel, pilih **Add New → Project**, lalu impor repository tersebut.
4. Framework preset pilih **Other** (atau biarkan terdeteksi sebagai static site).
5. Build command dan output directory dapat dikosongkan; file `index.html` berada di root proyek.
6. Klik **Deploy**.

## Deploy ke GitHub Pages
1. Unggah isi folder proyek ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu simpan.

## Catatan materi
Materi disusun sebagai pengantar belajar. Untuk pembelajaran akademik yang lebih mendalam, cocokkan kembali definisi, klasifikasi, dan analisis contoh dengan kitab atau referensi Balaghah yang digunakan di kelas.
